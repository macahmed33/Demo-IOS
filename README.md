# iOS Native Demo Project

A simple demo iOS application created to demonstrate how a native iOS project is structured and how user interactions trigger functionality internally.

This project is intentionally kept small and clean for learning, presentation, and interview/demo purposes.

## Overview

The app contains:

- Email input field
- Password input field
- Login button
- Basic validation
- Action handling and event flow
- Demonstration of native iOS architecture structure

The purpose is to understand how UI components interact with business logic and how user actions trigger methods in a native iOS application.
